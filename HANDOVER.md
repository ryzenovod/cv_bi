# Передача репозитория Елизавете

Сейчас сайт размещён в `ryzenovod/cv_bi` по адресу https://ryzenovod.github.io/cv_bi/ . Этот же адрес закодирован на визитке.

Нужен доступный GitHub-аккаунт Елизаветы и его точное имя. Передачу выполнять только после согласования с владельцами обоих аккаунтов. Репозиторий с таким же именем у получателя может помешать передаче — сначала проверить его наличие, ничего не удалять автоматически.

## Сохранение QR

GitHub перенаправляет адрес репозитория после передачи, но не адрес GitHub Pages. Это указано в [документации GitHub](https://docs.github.com/en/repositories/creating-and-managing-repositories/transferring-a-repository).

Практический вариант для уже напечатанной визитки:

1. Передать рабочий репозиторий Елизавете и дождаться принятия.
2. В её репозитории включить GitHub Pages через Actions, проверить deployment и новый сайт. Обновить `canonical`, `og:url`, `og:image` в HTML и URL в VCF. Относительные пути к стилям и фото менять не нужно.
3. В аккаунте `ryzenovod` создать новый маленький репозиторий `cv_bi`, содержащий только страницу перехода на новый сайт. Это заменит автоматическое перенаправление старого адреса репозитория; старые git remote следует обновить на нового владельца.
4. Опубликовать страницу перехода по прежнему адресу https://ryzenovod.github.io/cv_bi/ . В ней должны быть автоматический переход и обычная видимая ссылка на новый сайт.
5. Считать QR с готового макета и проверить весь переход до сайта Елизаветы. Старый репозиторий с перенаправлением сохранять, пока используются визитки.

Возможен краткий перерыв доступности во время переноса. Если требуется независимый от GitHub-аккаунтов адрес, сначала выбрать собственный домен, настроить его и пересобрать QR до печати. Покупка домена не входит в текущую работу.

При выпуске нового тиража обновить `SITE_URL` в `scripts/build_cards.py`, пересобрать макеты и снова проверить QR. Для прежнего тиража хранить исходные PDF с прежним QR.

## Файлы для передачи

Исходники сайта, фото, VCF, шрифты с OFL-лицензиями, исходники SVG, скрипт сборки и печатные PDF находятся в репозитории. Внешние сервисы аналитики, платные шрифты, API-ключи и серверная инфраструктура не используются.
